# Демо-профиль

Из этой папки берётся то, чем наполняется пустая база при `SEED_DEMO_DATA=true`:
названия муниципалитетов, паспорт проекта (цель, план, сроки) и дорожная карта.
Учреждения и штатные расписания генерируются кодом в `backend/app/seed.py`.

- `demo.json` — условный профиль, лежит в репозитории.
- `local.json` — свой профиль с настоящими названиями и плановыми цифрами.
  В git не попадает. Если файл есть, используется он.

Формат у обоих файлов один. Первый муниципалитет в списке — пилотный: в нём половина
учреждений и для него заводится паспорт проекта. Явно выбрать файл можно переменной
`SEED_FILE` в `.env`.

Профиль читается один раз, на пустой базе. Чтобы применить изменения, базу нужно
пересоздать: `docker compose down -v && docker compose up -d`.
