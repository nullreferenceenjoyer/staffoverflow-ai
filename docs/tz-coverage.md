Статусы: **да** — работает; **частично** — работает с оговорками; **нет** — не сделано.

## 2. Архитектура

| Требование | Статус | Комментарий |
|---|---|---|
| PostgreSQL для структурированных данных | да | Схема в `backend/app/models.py`, миграции Alembic |
| Объектное хранилище документов | частично | Файлы лежат в томе `storage`. S3-совместимого хранилища нет; путь к файлу хранится относительным, так что заменить бэкенд можно в одном месте |
| Векторное хранилище | да | pgvector, таблица `knowledge_chunks` |
| API-шлюз и микросервисы | частично | Один сервис API с модулями по границам из ТЗ плюс отдельный воркер. Причины — в README |
| Локальные LLM в контуре | да | llama.cpp в Compose или внешний сервер |
| Облачные API с возможностью отключения | да | Выключены по умолчанию; чувствительные запросы в облако не уходят никогда |
| Веб-интерфейс | да | |
| Бот в мессенджере | частично | MAX и Telegram. Транспорт MAX не проверен на живом боте. WhatsApp нет |
| Коннекторы ГИС, ЕФИС, 1С:ЗУП | частично | Только импорт выгрузок CSV/XLSX. API этих систем требуют уточнения, как и сказано в примечании к ТЗ |
